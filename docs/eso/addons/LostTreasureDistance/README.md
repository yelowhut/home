# Lost Treasure Distance

Плагин к аддону **Lost Treasure**: под каждой иконкой сокровища/исследования на компасе
показывает расстояние до неё в метрах.

Это отдельный аддон, а не форк — Lost Treasure обновляется через Minion, и правки внутри
него затёрлись бы при первом же обновлении.

## Как работает

Lost Treasure регистрирует компас-пины через `CustomCompassPins` и вешает на них свой
`additionalLayout` (`int/Pins.lua:148`, показ имени пина в центральной подписи компаса).
Плагин **оборачивает** этот layout: сначала вызывается оригинальный колбэк Lost Treasure,
затем свой, который рисует подпись с дистанцией.

Метры берутся из LibGPS: два замера по единичному квадрату дают «метров на единицу
карты» по X и по Y, дальше дистанция считается обычной арифметикой. Замеры кэшируются
по `mapId` — так LibGPS (который при отсутствии измерения умеет переключать карту) не
дёргается из обработчика `OnUpdate` компаса. Текст обновляется не чаще, чем раз в 200 мс.

## Почему не используется `GetLocalDistanceInMeters`

Эта функция LibGPS считает неверно — в версии 1.0.0 из-за неё дистанция завышалась
примерно вдвое (61 м показывались как 142 м):

```lua
-- TamrielOMeter.lua:293
math.sqrt(lx1 * lx1 * measurement.scaleX * worldSizeX + ...) * 0.01 * DEFAULT_TAMRIEL_SIZE
```

`Measurement:ToWorld()` (`Measurement.lua:90`) — авторитетное преобразование, ради
которого и калибруется `worldSize`, — переводит локальные координаты в мировые как
`worldSize · scaleX`. То есть `scaleX` и `worldSize` должны **перемножаться**, а
`GetLocalDistanceInMeters` берёт из их произведения корень. Ошибка равна
`sqrt(scaleX · worldSize)`.

`GetGlobalDistanceInMeters` этой ошибки не содержит и согласуется с `ToWorld`, поэтому
замеры делаются через `LocalToGlobal` + `GetGlobalDistanceInMeters`. Тот же путь
использует VEQ (`Includes/functions.lua:3219`).

## Проверка в игре

`/ltdistance` печатает масштаб текущей карты («метров на единицу карты») и дистанцию до
каждого пина Lost Treasure на ней — есть с чем сверить показания на местности.

## Важный нюанс с пулом пинов

Пул контролов компас-пинов в `CustomCompassPins` **общий для всех аддонов**: `ResetPin`
прогоняет reset-функции *всех* зарегистрированных layout'ов по *любому* выдаваемому пину.
Поэтому reset здесь прячет подпись безусловно — иначе дистанция до сокровища залипла бы,
например, на пине скайшарда из SkyShards.

## Настройки

Панель **Lost Treasure Distance** в настройках аддонов (LibAddonMenu): включение/выключение,
размер шрифта, вертикальный отступ подписи от иконки.

## Зависимости

`LostTreasure`, `CustomCompassPins`, `LibGPS`; опционально `LibAddonMenu-2.0` (без неё
аддон работает с настройками по умолчанию).
