# Miat's Tick Tracker — кастомная версия (visuals v1.16)

Форк аддона **Miat's Ticks Tracker** (Dorrino, обновление Asquart) с добавленным управлением
видимостью и размером. Это резервная копия правок — при обновлении аддона через Minion/вручную
оригинал перезапишет изменения, поэтому после апдейта их нужно накатить заново отсюда.

## Что добавлено к оригиналу (v1.15 → v1.16)

Всё настраивается в игре: **Настройки → Аддоны → Miat's Tick Tracker**.

Подменю **Visibility**:
- **Fade out of combat** — плавное затухание вне боя, в бою полная непрозрачность
  (событие `EVENT_PLAYER_COMBAT_STATE`, анимация alpha 300 мс).
- **Out-of-combat opacity (%)** — прозрачность вне боя (0 = невидимо, 100 = без затухания). Дефолт 30.
- **Fade delay after combat (sec)** — задержка перед затуханием после боя, 0–30 с. Дефолт 3.
- **Hide in cities / safe zones** — полностью прячет трекер в городах/интерьерах.

Подменю **Progress bar**:
- **Set tracker bar height (px)** — высота бара 10–80 px (в оригинале жёстко 27).

## Логика видимости

- Вне боя — затухание до заданной прозрачности после задержки (не жёсткое скрытие).
- Бой перекрывает и затухание, и скрытие в городе: в бою трекер всегда полный
  (актуально для данжей — они тоже сабзоны).
- Штатное «прятать при полном ресурсе» / «показывать всегда» не тронуто, работает поверх.

## Нюанс детекта городов

В ESO нет прямого флага «безопасный город». Используется признак:
город/интерьер = `MAPTYPE_SUBZONE` + `MAP_CONTENT_NONE` (данж = `MAPTYPE_ZONE` + `MAP_CONTENT_DUNGEON`),
оценка на `EVENT_PLAYER_ACTIVATED`. Надёжно ловятся столицы и интерьеры с экраном загрузки.
Открытые поселения без загрузочного экрана как «город» НЕ распознаются (для них нужен
белый список зон через LibZone — пока не сделано).

## Как переустановить после обновления аддона

Скопировать три файла обратно в папку аддона и сделать `/reloadui`:

```
docs/eso/addons/MiatsTickTracker/*.{lua,xml,txt}
  → C:/Users/<user>/Documents/Elder Scrolls Online/live/AddOns/MiatsTickTracker/
```

Изменённые файлы: `MiatsTickTracker.lua` (основная логика + меню), `MiatsTickTracker.txt`
(версия 1.16 / AddOnVersion 116). `MiatsTickTracker.xml` не менялся относительно оригинала —
включён для целостности.

SavedVariables (`MiatTickTrackerSettings`) не трогаются: новые настройки добавляются в дефолты
и подмешиваются автоматически, старые сохранённые позиции/цвета остаются.
