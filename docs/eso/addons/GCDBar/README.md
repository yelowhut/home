# GCD Bar — кастомная версия (visuals v2.7)

Форк аддона **GCD Bar** (автор Wheels) — полоска отсчёта глобального кулдауна — с добавленным
управлением визуалом и видимостью. Это резервная копия правок: при обновлении аддона оригинал
перезапишет изменения, поэтому после апдейта их нужно накатить заново отсюда.

Только изменённые файлы аддона. Библиотеки (`libs/`) и `LICENSE` не менялись — их вернёт свежая
установка, копировать не нужно.

## Что добавлено к оригиналу (v2.6 → v2.7)

Всё настраивается в игре: **Настройки → Аддоны → GCD Bar**.

Раздел **Size**:
- **Width / Height** — числовые ползунки размера (в оригинале размер менялся только перетаскиванием
  за уголок; drag-resize по-прежнему работает).
- **Scale (%)** — общий масштаб 50–300%. В оригинале SV `scale` был объявлен, но **нигде не
  применялся** — теперь работает через `gbFrame:SetScale`.

Прочее:
- **Background Color** — цвет и прозрачность подложки бара (в оригинале захардкожен чёрный 25%).

Раздел **Visibility**:
- **Fade out of combat** — плавное затухание вне боя, в бою полная непрозрачность
  (событие `EVENT_PLAYER_COMBAT_STATE`, анимация alpha 300 мс).
- **Out-of-combat opacity (%)** — прозрачность вне боя (0 = невидимо, 100 = без затухания). Дефолт 30.
- **Fade delay after combat (sec)** — задержка перед затуханием после боя, 0–30 с. Дефолт 3.
- **Hide in cities / safe zones** — полностью прячет бар в городах/интерьерах.

## Логика видимости

- Вне боя — затухание до заданной прозрачности после задержки.
- Бой перекрывает и затухание, и скрытие в городе: в бою бар всегда полный (актуально для данжей —
  они тоже сабзоны).
- Затухание применяется к «детям» контрола (фон + заливка), чтобы не конфликтовать с HUD-фрагментом
  сцены, который управляет alpha самого фрейма при переходах между сценами.
- Штатные «Lock UI / Hide Bar / Reverse / AB Cooldowns» не тронуты по смыслу; Hide Bar и Lock UI
  теперь идут через общий `updateVisibility`.

## Нюанс детекта городов

Как и в MiatsTickTracker: город/интерьер = `MAPTYPE_SUBZONE` + `MAP_CONTENT_NONE`
(данж = `MAPTYPE_ZONE` + `MAP_CONTENT_DUNGEON`), оценка на `EVENT_PLAYER_ACTIVATED`. Надёжно ловятся
столицы и интерьеры с экраном загрузки; открытые поселения без загрузочного экрана как «город»
НЕ распознаются (нужен белый список зон через LibZone — пока не сделано).

## Как переустановить после обновления аддона

Скопировать четыре файла обратно в папку аддона и сделать `/reloadui`:

```
docs/eso/addons/GCDBar/{GCDBar.lua,GCDBarUI.lua,GCDBarMenu.lua,GCDBar.txt}
  → C:/Users/<user>/Documents/Elder Scrolls Online/live/AddOns/GCDBar/
```

SavedVariables (`GCDBarSavedVars`, per-character) не трогаются: новые настройки добавляются в дефолты
и подмешиваются автоматически, старые позиции/цвета сохраняются.
