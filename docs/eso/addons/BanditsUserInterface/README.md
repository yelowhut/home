# Bandits User Interface — кастомная правка

Форк аддона **Bandits User Interface** (BUI, версия 4.437, APIVersion 101050). Резервная
копия правки: при обновлении аддона оригинал перезапишет изменение, поэтому после апдейта
его нужно накатить заново отсюда.

Только изменённый файл `BUI_Automation.lua`. Остальные файлы не менялись — их вернёт свежая
установка. `BanditsUserInterface.txt` приложен лишь для фиксации версии, под которую делалась
правка.

## Проблема

Кнопка **«Dungeon Quests»** в окне поиска подземелий (её добавляет опция *Activity finder:
Dungeon Quests*) отмечает данжи, где ещё не выполнен сюжетный квест (ради очков умений). После
сдачи квеста иконка «!» у данжа в списке пропадает корректно, **но кнопка всё равно продолжает
выбирать этот данж**. Временно лечилось через `/reloadui`.

## Причина

В `MarkPledges` (`BUI_Automation.lua`) иконка и флаг выбора считаются по-разному:

- **Иконка** пересобирается с нуля при каждом обновлении списка (`text=""` → добавить иконку
  или пусто по живой проверке `GetCompletedQuestInfo`), поэтому после сдачи квеста исчезает.
- **Флаг** `obj.needDungeonQuest` (по нему кнопка отмечает строки, `:332`) выставлялся только в
  одну сторону — без ветки `else`:

  ```lua
  if GetCompletedQuestInfo(DungeonIndex[id].quest) == "" then
      obj.needDungeonQuest = true
  end
  ```

Строки списка в ESO — переиспользуемые (pooled) контролы, они не пересоздаются. Раз выставленный
`true` оставался на контроле до пересоздания UI. Отсюда рассинхрон: игра видит квест сданным →
иконки нет, но на строке висит устаревший `needDungeonQuest = true` → кнопка её всё равно выбирает.
`/reloadui` помогал только потому, что при пересоздании UI флаги на контролах обнулялись.

## Правка

`if`-присваивание заменено на прямое, чтобы флаг синхронизировался с реальным статусом квеста
в обе стороны (и ставился, и сбрасывался одновременно с иконкой):

```lua
obj.needDungeonQuest = (GetCompletedQuestInfo(DungeonIndex[id].quest) == "")
```

Теперь после сдачи квеста и обновления списка (окно открывается заново либо `/reloadui`) кнопка
данж больше не выбирает.

## Как переустановить после обновления аддона

Скопировать файл обратно и сделать `/reloadui`:

```
docs/eso/addons/BanditsUserInterface/BUI_Automation.lua
  → C:/Users/<user>/Documents/Elder Scrolls Online/live/AddOns/BanditsUserInterface/BUI_Automation.lua
```

SavedVariables не затрагиваются.
