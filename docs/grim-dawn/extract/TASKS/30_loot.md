# Задание 30 — Лут-таблицы и источники дропа

Скрипт: `30_loot.py` → `data/grim-dawn/drop_sources.jsonl`, `loot_tables.json`
Отчёт: `REPORTS/30_loot.md`

## Цель

Ответить на вопрос **«с кого фармить предмет X»** и обратный **«что падает с монстра Y»**.

## Область (счётчики из gd.sqlite)

- `LootMasterTable` (922) — верхнеуровневые таблицы дропа
- `LootItemTable_DynWeight` (2663) — предметы с весами
- `LootRandomizerTable` (1081) / `LootRandomizer` (7984) — аффиксы (детально — задание 11,
  тебе они нужны только как ссылки)
- `Monster` (3735) — монстры; у них есть поля со ссылками на лут-таблицы
- `FixedItemContainer` — сундуки с фиксированным содержимым
- `SetPiecePool`, `SetPiece` — пулы сетовых предметов

## Что вытащить

**`drop_sources.jsonl`** — по строке на связку «источник → предмет»:
```
{"item": "records/items/.../x.dbr", "item_name": "...",
 "source": "records/creatures/.../boss.dbr", "source_name": "...",
 "source_kind": "monster|chest|quest|table",
 "weight": 12.0, "chance_hint": 0.03,     // если выводимо
 "monster_level": 75, "is_hero": true, "is_boss": true,
 "path": ["mastertable.dbr", "itemtable.dbr"]}   // цепочка, как дошёл
```
Разворачивай цепочку таблиц рекурсивно (мастер-таблица → под-таблицы → предметы),
**с защитой от циклов** и с ограничением глубины.

**`loot_tables.json`** — сами таблицы как есть, чтобы можно было перепроверить вывод.

## Монстры

Для каждого монстра-источника вытащи то, что поможет искать его в игре:
имя (тэг), уровень, `is_hero`/`is_boss`/`is_nemesis` (ищи по полям и/или по имени записи),
фракцию, и **любое поле, намекающее на регион/локацию**. Точных координат в `.arz` нет
(они в `world001.map`, это отдельное задание 31) — не выдумывай их.

## Особое внимание: Monster Infrequent (MI)

MI — предметы, падающие только с конкретных монстров, основа многих билдов.
Найди, как они помечены в данных, и сделай отдельный срез `mi_items` внутри
`loot_tables.json`: предмет → монстр(ы)-источник(и).

## Честность важнее полноты

Вероятности в GD зависят от сложности, уровня монстра и множителей. Если ты не можешь
корректно посчитать итоговый шанс — **не пиши выдуманное число**. Отдай веса как есть
и объясни в отчёте, чего не хватает для перевода весов в проценты.

## Спот-чек

Возьми одного известного босса/немезиду и покажи его таблицу дропа. И наоборот —
возьми один MI-предмет и покажи, с кого он падает.
