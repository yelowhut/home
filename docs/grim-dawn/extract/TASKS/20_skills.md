# Задание 20 — Мастерства и деревья навыков

Скрипт: `20_skills.py` → `data/grim-dawn/skills.json` (+ `skills_flat.jsonl`)
Отчёт: `REPORTS/20_skills.md`

## Цель

Полные деревья всех **10** мастерств с покачковым скейлингом. Это ядро любого билда.

## Стартовые точки (проверено)

- Мастерства: `records/skills/playerclass01/_classtraining_class01.dbr` … `playerclass10/…class10.dbr`,
  тип `Skill_Mastery`. `playerclass10` пришёл из `gdx3` (Fangs of Asterkarn) — не забудь его.
- Скиллы мастерства лежат в той же папке `records/skills/playerclassNN/*.dbr`.
- Имена мастерств: тэги `tagSkillClassName01`… (`tagSkillClassName01` = Soldier).

## Что вытащить на каждый навык

- `record`, `name` + `name_tag`, `description`, `mastery` (номер + имя), `type` (тип записи)
- `role`: активный / пассивный / трансмутер (`Skill_Transmuter`) / модификатор (`Skill_Modifier`)
- **Позиция в дереве**: уровень мастерства для разблокировки, требуемый родительский навык,
  `maxLevel` (обычно 12/16), `ultimateLevel` (ультимативные очки сверх кэпа, до 22/26)
- **Зависимости**: что этот навык модифицирует (`Skill_Modifier` ссылается на базовый навык),
  какие трансмутеры к нему есть, какие модификаторы висят
- **Стоимость и КД**: энергия за каст (может быть массивом по уровням), кулдаун, длительность
- **Скейлинг по уровням**: в `.dbr` многие поля — **массивы длиной = число уровней навыка**.
  Это самое ценное. Сохрани массивы целиком (`{"поле": [v1, v2, ...]}`), не бери только 1 уровень.
- **Урон/эффекты**: типы урона, %оружия (`skillWeaponDamage`), радиус, число целей,
  бонусы к статам для пассивок/аур

## Структура выхода

`skills.json` — иерархия: мастерство → навыки → (модификаторы, трансмутеры).
`skills_flat.jsonl` — плоский список всех навыков для быстрого поиска.

## На что обратить внимание

- Навыки, гранты которых дают предметы (`records/skills/itemskills/…`) — **тоже включи**,
  отметив `source: "item"`. Это важно для билдов (проки с предметов).
- Не тащи сюда девоушены (`records/skills/devotion/…`) — это задание 21.
- Многие поля повторяются между типами скиллов. Составь в отчёте таблицу самых частых
  полей и их смысла — она пригодится всем остальным.
