# Path of Exile 2 — запуск под ограниченным пользователем `gamer`

Runbook: как запускать PoE2 под отдельным ограниченным пользователем `gamer` через ярлык
на рабочем столе, **без отдельной сессии/входа** (ПК `HOME-PC`, Windows 11).

## Итоговая рабочая конфигурация

| Компонент | Значение |
|---|---|
| Пользователь | `gamer` — обычный (группа `Users`), без прав администратора |
| Установка игры | `C:\games\Path of Exile 2 - poe2_production` |
| Лаунчер игры | `PathOfExile_x64.exe` (маленький; спавнит `PathOfExile.exe`, 74 МБ) |
| Батник запуска | `C:\poe2\poe2.bat` |
| Ярлык | `runas.exe /savecred /user:gamer "cmd /c C:\poe2\poe2.bat"` |
| Пароль | сохранён в Credential Manager пользователя `yelow` (`/savecred`) |

`C:\poe2\poe2.bat`:
```bat
@echo off
cd /d "C:\games\Path of Exile 2 - poe2_production"
start "" "PathOfExile_x64.exe"
```

## ⚠️ Ключевой нюанс (стоил нескольких часов диагностики)

**Нельзя запускать exe игры напрямую через `runas`** — игра мгновенно падает с
`0xc0000005` (access violation) ещё до записи собственного лога. Причина: процесс
наследует консоль `runas.exe`.

**Решение:** запуск через промежуточный `cmd /c` + `start` в батнике — это отвязывает
игру от консоли `runas`, и всё работает.

Что **не** помогло (проверено): прямой `runas <exe>`; `runas` с правильной рабочей
директорией; shell-глагол `runasuser` через скрипт; засев конфига/смена режима экрана.
Помог **только** паттерн `cmd + batch + start`.

Ровно эта же команда работала на старом ПК (тогда имя было `SAS-PC`):
`runas.exe /savecred /user:SAS-PC\gamer "cmd /c C:\poe2\poe2.bat"`.

## Прочее

- `PathOfExile.exe` имеет манифест `asInvoker` — админ не требуется; `gamer` работает на
  среднем уровне целостности, как и обычный запуск под `yelow`.
- Служба **Secondary Logon** (`seclogon`) должна быть включена (Manual) — нужна для `runas`.
- `gamer` имеет полный доступ к папке игры и `RX` на `C:\poe2`.
- `/savecred` спрашивает пароль `gamer` один раз при первом запуске, дальше — без запроса.

## Восстановление после переустановки игры

1. Убедиться, что путь установки и имя лаунчера (`PathOfExile_x64.exe`) не изменились.
2. Ярлык и батник должны указывать на `cmd /c C:\poe2\poe2.bat` (НЕ на exe напрямую).
3. Перепроверить ACL папки игры для `gamer`.
4. Скрипт первичной настройки: `C:\Users\yelow\setup-gamer-poe2.ps1` (создаёт пользователя,
   права, батник и ярлык). Запускать от администратора.
