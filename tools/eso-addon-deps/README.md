# eso-addon-deps

Проверка и доустановка зависимостей (библиотек) для уже установленных аддонов
The Elder Scrolls Online. Один файл, только стандартная библиотека Python 3.9+.

## Запуск

```powershell
python tools\eso-addon-deps\eso_deps.py
```

Путь к `AddOns` по умолчанию — `%USERPROFILE%\Documents\Elder Scrolls Online\live\AddOns`.

Порядок работы:

1. показывает список установленных аддонов с индикатором:
   🟢 обязательные зависимости в порядке · 🟡 версия ниже требуемой · 🔴 зависимостей нет;
2. если всё закрыто — предлагает завершить работу (при ответе «нет» показывает
   список неустановленных опциональных);
3. иначе печатает план: что за библиотека, какая версия нужна, номер на ESOUI,
   каким аддонам она нужна, — и спрашивает подтверждение;
4. перед установкой делает zip-бэкап всей папки `AddOns` рядом с ней
   (`live\AddOns-backup-<дата>-<время>.zip`) и печатает путь;
5. ставит библиотеки и **повторяет проход**, потому что у библиотек есть свои
   зависимости (например `LibHistoire`/`LibGPS` тянут `LibAsync`);
6. заново сканирует папку и печатает итоговый статус.

## Ключи

| Ключ | Смысл |
|---|---|
| `--dry-run` | показать план и выйти, ничего не менять |
| `--yes` | не задавать вопросов |
| `--optional` | учитывать и `OptionalDependsOn` |
| `--only Имя1,Имя2` | поставить только указанные (в т.ч. опциональные) |
| `--addons-dir PATH` | другая папка `AddOns` (удобно для проверки на копии) |
| `--platform pc\|console` | какие платформенные зависимости считать обязательными (по умолчанию `pc`) |
| `--refresh` | перекачать каталог ESOUI, минуя кэш |
| `--no-color` | без ANSI-цвета |
| `--cache-dir PATH` | где держать кэш каталога (по умолчанию `%LOCALAPPDATA%\eso-addon-deps`) |

## Как это работает

Источник истины о зависимостях — манифесты аддонов. Манифестом считается файл
`<Имя>.txt` **или** `<Имя>.addon` внутри папки `<Имя>`; оба расширения реально
встречаются, и парсер только по `*.txt` даёт ложную картину «мод без зависимостей».
Обход рекурсивный: игра грузит и вложенные аддоны (`VotansImprovedLocations\VotansSurveyTheWorld`).

Обязательные зависимости объявляются **тремя** директивами, и читать надо все:

| Директива | Когда обязательна |
|---|---|
| `## DependsOn` | всегда |
| `## PCDependsOn` | на PC |
| `## ConsoleDependsOn` | на консоли |

Это не тонкость, а главная ловушка: `BeamMeUp` просит `LibZone` и `LibScrollableMenu`
только через `PCDependsOn`, а `QuestMap` — `LibMapPins-1.0`, `LibQuestData`, `LibMapData`
тоже только через неё. Парсер, читающий один `DependsOn`, покажет такие аддоны
зелёными, а в игре они не заработают. Зависимости неактивной платформы видны в
таблице как «+N для др. платформы» и не считаются обязательными.

Кроме этого читаются `## OptionalDependsOn`, `## AddOnVersion`, `## APIVersion`,
`## IsLibrary`, `## Title`. Ограничение версии вида `LibFoo>=42` сравнивается
с целым `## AddOnVersion` установленной библиотеки.

Резолвинг имени в файл на ESOUI — через публичный каталог MMOUI (тот же, что у Minion):

- `https://api.mmoui.com/v3/game/ESO/filelist.json` — у каждой записи есть `UIDir`,
  список папок, которые создаст архив. Он и даёт индекс «имя папки → ID файла».
  Кэшируется на 24 часа.
- `https://api.mmoui.com/v3/game/ESO/filedetails/<id>.json` — прямая ссылка на zip и `UIMD5`.

Если папку заявляют несколько записей (библиотека вложена в чей-то архив), выбор
по приоритету: совпадение `UIName` → первая папка в `UIDir` → архив из одной папки
→ популярность. Скрипт печатает, когда выбор был неоднозначным.

## Что важно знать

- **Версию до скачивания сверить нельзя.** В каталоге `UIVersion` — строка вида
  `2.0 r43`, а ограничения в манифестах — целое `AddOnVersion`. Поэтому требование
  `>=N` проверяется уже после установки, при повторном сканировании; если версия
  всё равно ниже, это видно в итоговом статусе жёлтым.
- **Целостность.** Скачанный zip сверяется с `UIMD5` из каталога; распаковка
  защищена от zip-slip (пути вне `AddOns` и `..` отклоняются).
- **Ничего не удаляется.** Новые библиотеки создают новые папки; уже существующая
  папка перезаписывается только если это заявлено в плане как «обновление».
- `SavedVariables` не читаются и не трогаются.
- **Заблокированные файлы.** Если запущена игра или клиент Tamriel Trade Centre,
  часть файлов занята (`TamrielTradeCentre\Client\TTC_Lock`). Такие файлы в бэкап
  не попадают, скрипт их перечисляет и спрашивает, продолжать ли. На восстановление
  аддонов они не влияют, но полный бэкап лучше делать при закрытой игре.
- **Опциональные зависимости ставить обычно не нужно.** Часть из них — это не
  библиотеки, а самостоятельные аддоны, с которыми интегрируются установленные
  (`MasterMerchant`, `pChat`, `AdvancedFilters`), а часть — декларация порядка
  загрузки для скиннинга (весь опциональный список `PerfectPixel`). Поэтому по
  умолчанию они только показываются в отчёте.
- **Папки без манифеста** выводятся отдельной строкой: игра их не грузит. В текущей
  установке такая одна — `Ravalox'QuestTracker`, заглушка-указатель на переименованный
  `RavaloxsQuestTracker`.

## Восстановление из бэкапа

Распаковать `AddOns-backup-<дата>.zip` в `...\Elder Scrolls Online\live\`
(архив содержит папку `AddOns` целиком). Старые папки заменятся, лишние
доустановленные останутся — их при необходимости удалить вручную.
