# Phantom Brigade — локальная вики снаряжения

Оффлайн-база знаний по деталям мехов игрока (корпуса, оружие, ранцы) и
модификациям. Все данные вытащены **из локальных файлов игры**, без интернета.

## Как открыть

Просто откройте **`index.html`** двойным кликом. Рядом должен лежать
`data.js` (сгенерированная база + иконки). Ничего ставить/запускать не нужно.

## Возможности

- **Таблица** (по умолчанию) с сортируемыми колонками и барами статов +
  переключатель на **карточки** (иконка ≣/⊞ справа вверху).
- **Поиск** по названию, описанию, тегам, ключу (рус./англ.); горячая клавиша `/`.
- **Фасетные фильтры** со счётчиками (обновляются динамически): тип слота,
  набор-корпус (Стрела, Асгард, Бейн, Ворон, Эльбрус, Хакобу, Хельге, Нокс,
  Тсубаса, Видар), вес, категория, производитель.
- **Диапазонные фильтры** (урон/дальность/тепло/масса) двойным слайдером.
- **Активные фильтры чипами** над таблицей, каждый с ×, кнопка «Сбросить всё».
- **URL-состояние**: вкладка, фильтры, поиск, сортировка, открытый предмет и
  сравнение сохраняются в адресе — можно расшарить/добавить в закладки, работает
  «Назад». Всё это — и через `file://`.
- **Tooltip при наведении** на строку/карточку — быстрый предпросмотр статов.
- Иконки статов/категорий — из ассетов игры; бары окрашены цветами статов из
  данных игры.
- **Детальная панель** (открывается справа, список не перекрывается):
  - **Ползунок уровня 1–99** — пересчитывает HP / Барьер / Урон юниту
    (+25 % за уровень, линейно; прочие статы фиксированы — это факт из
    `simulation.yaml`).
  - **Переключатель редкости** (Обычное / Необычное / Редкое) — показывает,
    какие **слоты модификаций** открываются: белый = база, зелёный = необычное,
    синий = редкое.
  - Полный список характеристик, состав (бронепластины / ядро оружия),
    особенности.
- **Вкладка «Модификации»** — модули по слотам, сгруппированы по семействам
  с тирами R1/R2/R3.
- **Сравнение** — кнопка «+» на карточках → таблица с подсветкой лучшего/худшего.

## Обновление базы (после патча игры)

```
python extract.py
```

Требуется Python 3 + пакеты:

```
python -m pip install PyYAML UnityPy
```

Скрипт читает `Configs/DataDecomposed/Equipment`, `UnitStats`, `QualityTables`,
текстовые таблицы (русская локализация + английский фолбэк) и иконки из
`PhantomBrigade_Data/*.assets`, затем пишет `data.js`.

Путь к игре задан в начале `extract.py` (`GAME = ...`).

## Что важно знать про данные

- **Оружие / ранцы**: числа берутся напрямую из сабсистем — точные значения.
- **Броня (торс/ноги/руки)**: значения барьера/HP/массы — это **доля от общего
  запаса набора** (ровно как в файлах игры). Осмысленно сравнивать части между
  собой; абсолютный HP зависит от базовых статов юнита и считается движком.
- **Уровень** предмета в игре задаётся прогрессом кампании (не хранится в
  статике). Технический потолок — 99; в мастерской предмет можно докачать на +3
  сверх найденного.
- **Редкость** (rating 0–3) добавляет слоты под модули, но **не** повышает
  базовые числа.
