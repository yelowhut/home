# Ember Knights — Honest Damage (мод)

Показывает реальный текущий урон способностей/скиллов/оружия/реликвий с учётом
статов; на экране наград — прогноз «сейчас → станет» от предлагаемого предмета.

> **Статус сборки: ДИАГНОСТИЧЕСКАЯ (этап 1 из 2).**
> Готово и собрано: вычислительное ядро, генерация IL2CPP-interop, загрузчик
> BepInEx, чтение статов игрока и **калибровочная диагностика**.
> Ещё НЕ включено: вывод чисел поверх игрового UI (суффиксы и what-if). Точки
> вставки в интерфейс невозможно определить из дампа — игровые UI-классы
> `*Refs` не содержат логики. Их нужно найти по диагностическому логу с
> запущенной игры (раздел `[UI-TREE]`), после чего я доделаю отображение.
> **Поэтому: установи, нажми F9 в бою и пришли `honest-damage-diag.log`.**

## Установка

1. Закрой игру.
2. Скопируй **всё содержимое** папки `dist/BepInEx-pack/` в папку игры
   (рядом с `EmberKnights_64.exe`):
   `C:\Program Files (x86)\Steam\steamapps\common\EmberKnights`
   После копирования там появятся `winhttp.dll`, `doorstop_config.ini`,
   `dotnet\`, `BepInEx\`. Плагин уже лежит в
   `BepInEx\plugins\` (`HonestDamage.Plugin.dll` + `HonestDamage.Core.dll`).
3. Запусти игру. **Первый запуск будет долгим (~1–2 мин)** — BepInEx
   один раз генерирует IL2CPP-interop своим v31-совместимым Cpp2IL (окно может
   «висеть» — это нормально, дождись меню). Последующие запуски быстрые.
   В `BepInEx\LogOutput.log` должны появиться строки `Honest Damage loaded` и
   `[AttribSanityCheck] OK`.

> Требуется **BepInEx 6.0.0-be.735** (он в пакете). Более старый be.697 НЕ
> работает с этой игрой (metadata v31): старый Cpp2IL + падение bootstrap.

## Что делать сейчас (сбор калибровочных данных)

1. Зайди в забег, возьми оружие/реликвии/апгрейды как обычно.
2. **Получи один удар** по персонажу (диагностика кэширует игрока по факту
   получения урона — это временно).
3. Нажми **F9** — это запишет `BepInEx\honest-damage-diag.log` с разделами:
   - `[ATTRIBS]` — для каждого стата: значение игры `Get` | база `GetRaw` |
     значение, пересчитанное модом. Это проверяет, что моя репликация формулы
     статов совпадает с игрой.
   - `[MODIFIERS]` — все активные модификаторы (от чего какой стат меняется).
   - `[UI-TREE]` — дерево открытого интерфейса (имена объектов, компоненты,
     тексты). По нему я найду, куда вставлять числа.
4. Чтобы записать урон конкретной способности: включи в конфиге
   `Verbose = true` (см. ниже), сделай несколько атак — в `LogOutput.log`
   запишутся реальные значения урона (`DamageAmount`, `AbilityDefId` и т.д.,
   не чаще ~1 строки/сек).
5. **Пришли оба файла** (`honest-damage-diag.log` и `LogOutput.log`) — по ним
   я доделаю отображение чисел в UI и откалибрую формулу.

## Горячие клавиши и настройки

- **F8** — переключатель оверлея (пока без видимого эффекта — вывод в UI ещё
  не подключён).
- **F9** — записать диагностический дамп.
- Конфиг создаётся при первом запуске:
  `BepInEx\config\com.ashubin.ekhonestdamage.cfg`
  (клавиши, `Verbose`, флаги поверхностей).

## Совместимость / мультиплеер

Мод **read-only**: не меняет игровое состояние и не шлёт сетевых сообщений —
перехват урона работает как постфикс только на чтение. Ванильный игрок может
зайти к вам в лобби; проверка версии сверяет константу билда в нетронутом
`GameAssembly.dll`, которую мод не меняет. Используй в одиночке или приватных
лобби. Известное ограничение: в кооперативе кэш игрока берёт последнего, кто
получил урон (в соло всегда корректно).

## Сборка из исходников (для разработчика)

- .NET SDK 8 (проект: `HonestDamage.sln`).
- Ядро `src/HonestDamage.Core` — чистый netstandard2.1, юнит-тесты в
  `tests/HonestDamage.Core.Tests` (`dotnet test`).
- Плагин `src/HonestDamage.Plugin` (net6.0) ссылается на:
  - локальные interop-сборки `lib/interop/` — генерируются скриптом
    `build/gen-interop.ps1` из `GameAssembly.dll` + `global-metadata.dat`
    (офлайн, без запуска игры);
  - core-сборки BepInEx 6.0.0-be.735 из `build/tools/BepInEx-be735/BepInEx/core/`.
- Важно: игра использует IL2CPP metadata v31 (Unity 2022.3.62f3). BepInEx be.697
  НЕ поддерживает v31 (его Cpp2IL слишком старый, и его IL2CPP-bootstrap падает с
  BadImageFormatException). Используется be.735: v31-совместимый Cpp2IL +
  обновлённый bootstrap. Il2CppInterop (1.4.6-ci.426) побайтово идентичен между
  be.697 и be.735, поэтому ABI плагина не меняется.
- Готовый пакет собирается в `dist/BepInEx-pack/` (gitignored) скриптом
  `build/deploy-pack.ps1 -Target dist|live`.

## Дорожная карта (этап 2, по твоему логу)

1. По `[UI-TREE]` — найти реальные классы/тексты окна оружия, инвентаря и
   экрана наград; подключить аддитивные суффиксы (оригинал не трогаю).
2. По логу урона — откалибровать формулу `DamageModel` (как ATK/криты/
   модификаторы дают итоговый урон).
3. Включить what-if дельту на экране наград (расчёт уже готов в ядре).
